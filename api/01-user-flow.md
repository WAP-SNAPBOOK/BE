## A. 점주 온보딩 플로우

### 1. 회원가입

- 카카오 OAuth 로그인
- 점주(OWNER) 역할로 회원가입

### 2. 매장 생성

- 상호명, 사업자번호, 주소 입력

### 3. 운영 시간 설정

| 단계              | 설명                                                                                   |
|-----------------|--------------------------------------------------------------------------------------|
| 3-1. 운영시간 타입 선택 | `DAILY`(매일 같음), `WEEKDAY_WEEKEND`(평일/주말), `BY_DAY`(요일별)                              |
| 3-2. 시간 설정      | 시작/종료 시간(마지막으로 예약받는 시간) 입력, `BY_DAY` 선택 시 월~일 중 선택 후 입력. "시간 추가" 버튼으로 다른 요일 그룹 추가 가능 |
| 3-3. 간격 설정      | 30분 또는 1시간 (예약 슬롯 단위)                                                                |

### 4. 휴무일 설정

| 단계            | 설명                                                 |
|---------------|----------------------------------------------------|
| 4-1. 정기 휴무일   | 주기 선택: `WEEKLY`(매주), `BIWEEKLY`(격주), `MONTHLY`(매달) |
|               | MONTHLY 선택 시: 첫째~다섯째 주 중 선택                        |
|               | 요일 선택: 월~일                                         |
|               | `BIWEEKLY`(격주) 선택 시, 기준일 설정. (기준일 기준으로 격주를 계산)     |
| 4-2. 공휴일 휴무   | 공휴일에 자동 휴무 여부 토글                                   |
| 4-3. 특정 날짜 휴무 | 달력에서 날짜 직접 선택하여 `CUSTOM` 휴무 추가                     |

### 5. 직원 추가

| 단계            | 설명                                           |
|---------------|----------------------------------------------|
| 5-1. 이름 입력    | 직원명                                          |
| 5-2. 운영 시간 설정 | "매장 기본 운영시간과 동일" 체크 가능, 또는 개별 요일별 시간 설정      |
| 5-3. 정기 휴무일   | 매장과 동일한 방식: 주기(WEEKLY/BIWEEKLY/MONTHLY) + 요일 |
| 5-4. 공휴일 휴무   | 직원별 공휴일 휴무 여부 토글                             |
| 5-5. 특정 날짜 휴무 | 달력에서 직원 개인 휴무일 추가                            |

### 6. 태그 추가

- 매장에서 사용할 태그 생성 (예: "네일", "속눈썹", "왁싱")

### 7. 메뉴 추가

| 단계                 | 설명                                     |
|--------------------|----------------------------------------|
| 7-1. 태그 추가         | 메뉴 분류 태그 생성                            |
| 7-2. 메뉴 등록         | 이름, 설명, 가격, 순서(sortOrder) 입력           |
| 7-3. 입력 필드 추가 (선택) | 메뉴별 추가 입력 필드: 타입(TEXT/NUMBER), 필수 여부 등 |

## B. 고객 예약 플로우 (채팅방 -> 예약)

**전제**: 고객이 공유 링크(`/s/{slug}`)를 통해 채팅방에 입장한 상태

### 1. 날짜 선택 (캘린더)

- 월별 캘린더에서 예약 가능 날짜 조회
- 표시 규칙:
    - 예약 가능: 기본 색상
    - 예약 불가/휴무일: 회색
    - 공휴일: 빨간색

### 2. 시간 선택

- 선택한 날짜의 예약 가능 시간 슬롯 조회
- 이미 점유된 슬롯: 회색 표시
- 시간 선택 후 "다음" 버튼

### 3. 메뉴 선택

- 매장의 첫 번째 태그가 기본 선택된 상태로 메뉴 조회
- 태그 변경 시 해당 태그의 메뉴만 필터링 표시
- 메뉴 선택, 입력 필드가 있으면 값 입력 후 "다음" 버튼

### 4. 예약 확정

- 요구사항(텍스트) 입력 (선택)
- 사진 첨부 (선택)
- "예약" 버튼으로 예약 생성
