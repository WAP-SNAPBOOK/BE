# #105 Backlog - 테스트 가독성/모킹 개선

## 배경
- `#105` 진행 중 Reservation 테스트를 점검하면서 후속 개선 필요 항목이 확인됨.
- 현재 이슈의 범위(계약 전환/문서 정합화) 바깥이므로 backlog로 분리함.

## 항목

### 1. Reservation 테스트 `@DisplayName` 사용 기준 통일
- 문제:
  - 일부 테스트는 `@DisplayName`을 사용하고, 일부 테스트는 메서드명만 사용해 표현 방식이 혼재됨.
- 목표:
  - Reservation 계열 테스트에서 `@DisplayName` 적용 기준을 정하고 일관되게 맞춘다.
- 완료 기준:
  - 기준 문서화(간단 규칙)
  - 대상 테스트 일괄 정리 후 리뷰 가능 상태

### 2. Reservation 서비스 단위테스트 모킹 축소
- 문제:
  - `ReservationService` 단위테스트에서 의존성 수가 많아 setup 복잡도와 유지보수 비용이 큼.
- 목표:
  - 테스트가 실제 검증하는 협력자만 모킹하도록 구조를 단순화한다.
- 완료 기준:
  - 테스트 헬퍼/빌더 또는 서비스 책임 분리로 불필요 mock 감소
  - 핵심 시나리오 테스트의 가독성 개선(세팅 코드 축소)
