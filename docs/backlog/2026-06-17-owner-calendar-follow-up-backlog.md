# 점주/직원용 캘린더 후속 백로그

작성일: `2026-06-17 19:01 +09:00`  
기준 논의: `#128` 점주/직원용 캘린더 조회 API

## 배경

`#128`은 점주/직원용 캘린더의 조회 API에 집중한다.  
상단 7일 날짜 스트립, 선택일 타임라인, 직원 컬럼, 미지정 컬럼, 운영시간/휴무일 기반 표시, 예약 요약 응답까지를 `#128`의 우선 범위로 둔다.

아래 항목은 캘린더 조회 API와 함께 논의되었지만, 구현 단위가 커지므로 후속 백로그로 분리한다.

## `#128`에서 제외할 항목

- 예약 상세 바텀시트 보강
- 캘린더 내 예약 확정/수정/거절/취소 액션
- 예약 변경 이력 저장 및 조회
- 확정/수정/거절/취소 시 고객 자동 채팅 메시지
- 직원 로그인/권한 모델

## 후속 백로그 1. 예약 상세 바텀시트 지원

### 목표

캘린더 예약 블록을 눌렀을 때 상세 바텀시트에서 예약의 전체 정보를 확인할 수 있게 한다.

### 포함 후보

- 고객명
- 고객 연락처
- 예약 상태
- 예약 시간
- 소요시간
- 담당 직원
- 요청사항
- 첨부 사진 썸네일
- 선택 메뉴 목록
- 메뉴별 `priceSnapshot`
- 총액
- `변경 이력 보기` 진입

### 가격 표시 정책

- 가격 있는 메뉴만 합산한다.
- 가격 없는 메뉴는 `가격 미정`으로 표시한다.
- 일부 메뉴만 가격이 없으면 총액 옆에 `일부 메뉴 가격 미정`을 표시한다.
- 모든 메뉴 가격이 없으면 `총액 미정`으로 표시한다.

### 제외

- 캘린더 조회 응답에 전체 상세 정보를 포함하지 않는다.
- 사진 URL, 전체 메뉴, 요청사항, 고객 연락처는 예약 상세 조회에서만 내려준다.

## 후속 백로그 2. 캘린더 예약 액션

### 목표

점주가 캘린더 상세 바텀시트에서 예약을 운영 상태에 맞게 처리할 수 있게 한다.

### 포함 후보

- `PENDING` 예약 확정
- `PENDING` 예약 거절
- `CONFIRMED` 예약 수정
- `CONFIRMED` 예약 취소
- 담당 직원 지정/변경
- 시작 시간 변경
- 소요시간 변경
- 점주 전달 메시지 입력

### 정책

- 초기 캘린더 API는 점주 인증 사용자 전용이다.
- `PENDING` 확정 시 담당 직원 선택/변경을 허용한다.
- `미지정` 예약은 확정 전에 담당 직원 선택을 필수로 한다.
- `CONFIRMED` 수정 가능 항목은 시작 시간, 소요시간, 담당 직원, 점주 전달 메시지로 제한한다.
- `PENDING`은 거절로 처리하고, `CONFIRMED`는 취소를 지원한다.
- 거절/취소 사유는 필수다.
- 과거 예약도 확정/수정/거절/취소 가능하다.

### 시간 정책

- `PENDING` 캘린더 블록은 초기 30분 고정이다.
- 확정 폼 기본 소요시간은 30분이다.
- 예약 시작 시간 선택/수정은 30분 단위다.
- 예약 소요시간 선택/수정은 30분 단위다.
- 최대 소요시간은 180분이다.

### 충돌 정책

- 확정/수정 시 `staffId + startAt + durationMinutes` 기준으로 충돌을 검사한다.
- 충돌 시 액션은 실패한다.
- 사용자 메시지는 `해당 담당자의 선택 시간대에 이미 예약이 있습니다.` 수준의 간단한 메시지로 표시한다.

## 후속 백로그 3. 예약 변경 이력

### 목표

예약 확정/수정/거절/취소 이력을 별도 테이블로 남겨 운영 기록과 고객 안내 추적이 가능하게 한다.

### 저장 후보

- `reservationId`
- 변경한 사용자 `ownerUserId`
- 변경 타입: `CONFIRMED`, `UPDATED`, `REJECTED`, `CANCELED`
- 변경 전/후 `startAt`
- 변경 전/후 `durationMinutes`
- 변경 전/후 `staffId`
- 사유
- 점주 전달 메시지
- 생성 시각

### 조회 정책

- 캘린더 조회 응답에는 변경 이력을 포함하지 않는다.
- 캘린더에는 최신 예약 상태만 표시한다.
- 예약 상세 바텀시트에서 `변경 이력 보기` 버튼을 제공한다.
- 변경 이력은 별도 조회 API로 제공한다.

## 후속 백로그 4. 고객 자동 채팅 메시지

### 목표

점주가 예약 상태나 예약 정보를 변경하면 고객에게 채팅 시스템 메시지로 자동 안내한다.

### 발송 이벤트

- 예약 확정
- 예약 수정
- 예약 거절
- 예약 취소

### 메시지 정책

- 예약 확정 시 최종 예약 시간, 소요시간, 담당자, 메뉴 요약을 안내한다.
- 예약 시간이 변경되어 확정되면 변경 사실을 명확히 안내한다.
- 예약 수정 시 변경된 항목과 최종 예약 요약을 함께 안내한다.
- 예약 거절/취소 시 사유를 포함한다.
- 과거 예약 변경에도 고객 자동 메시지를 발송한다.
- 점주 전달 메시지가 있으면 자동 메시지와 함께 노출한다.

## 후속 백로그 5. 직원 계정 권한 확장

### 현재 결정

현재 `Staff`는 로그인 주체가 아니라 매장 내부 리소스다.  
따라서 `#128`과 초기 후속 작업은 점주 인증 사용자 기준으로 설계한다.

### 향후 확장 후보

- 직원 로그인 주체 도입
- 직원도 전체 직원 예약 조회 가능
- 직원도 타직원 `PENDING` 예약 조회 가능
- 직원도 `미지정` 컬럼 조회 가능
- 직원은 예약 확정/수정/거절/취소 불가
- 직원은 고객 연락처 조회 가능
- 조회 응답에 `viewerRole`, `canManage`, `availableActions` 같은 권한 정보를 포함

## `#128` 조회 API에 남길 핵심 범위

- 점주 인증 사용자 전용 캘린더 조회 API
- 특정 `shopId` 기준 조회
- 선택 날짜 기준 일요일 시작 7일 스트립
- 선택일 하루 타임라인
- 첫 진입은 전체 직원 보기
- 선택적 `staffId` 필터
- 전체 보기에서 활성 직원 전체를 컬럼으로 표시
- 직원 컬럼은 가로 스크롤 전제
- `미지정` 예약이 있으면 맨 오른쪽 끝에 `미지정` 컬럼 표시
- `미지정` 예약이 없으면 `미지정` 컬럼 숨김
- 특정 `staffId` 필터에서는 해당 직원 1개 컬럼만 반환
- 특정 `staffId` 필터에서는 `미지정` 컬럼 제외
- 날짜 스트립 배지는 현재 화면 범위 기준으로 계산
- `PENDING` 우선, 그다음 `CONFIRMED`
- `CANCELED`, `REJECTED`는 기본 캘린더에서 제외
- 휴무일/운영시간 없는 날에도 예약이 있으면 표시
- 휴무일 예약 존재 시 시간축은 예약 범위에 앞뒤 30분 여백 적용
- 시간축은 1시간 라벨과 30분 보조선으로 표시
- 예약 블록 높이는 소요시간에 비례
- 예약 블록에는 고객명, 시간, 대표 메뉴명, 상태 라벨 표시
- 메뉴가 여러 개면 첫 번째 메뉴명과 `외 N개`로 표시
