## PRD

### 확정된 정보
- Goal:
  - 네일샵 예약 기능의 제품 요구사항을 정의한다.
  - 고객은 유효한 예약 가능 시간에 대해 예약 요청을 생성할 수 있어야 한다.
  - 점주는 예약을 확정, 거절, 취소, 수정할 수 있어야 한다.
- Actor / User:
  - 고객
  - 점주
- User Problem:
  - 고객은 실제 예약 가능한 시간만 선택하고 싶다.
  - 고객은 예약 시 요청사항, 이미지, 메뉴 선택 정보를 함께 전달하고 싶다.
  - 점주는 운영 가능한 예약만 받고 싶고, 예약 요청을 유연하게 관리하고 싶다.
  - 고객 당일 미방문/취소 연락 같은 운영 상황에서도 일정 슬롯을 통제할 수 있어야 한다.
- User Scenario:
  - 고객이 예약 가능한 날짜와 시간을 확인한 뒤 예약 요청을 생성한다.
  - 점주가 요청을 보고 확정하거나 거절한다.
  - 예약 이후 고객 또는 점주가 정책에 따라 취소하거나, 점주가 예약 정보를 수정한다.
  - 고객과 점주는 각자 예약 목록과 상세를 조회한다.
- Success Outcome:
  - 고객은 예약 가능한 슬롯에서만 예약을 생성할 수 있다.
  - 점주는 예약 상태와 일정 슬롯을 일관되게 관리할 수 있다.
  - 취소 정책, 수정 정책, 에러 계약이 문서와 테스트에서 동일하게 해석된다.
- Out of Scope:
  - 예약금 결제/환불 자체 처리
  - `COMPLETED`, `NO_SHOW` 실제 구현
  - 통계/정산/패널티 기능
