# `#131` 예약 취소 자동 메시지 프론트 전달 문서

작성일: `2026-06-18`

## 범위

예약 취소 시 고객 채팅방에 시스템 메시지를 자동으로 남긴다.  
이번 이슈는 취소 이벤트의 자동 메시지 연결만 포함한다.

## 결정사항

- 취소 메시지 타입은 `RESERVATION_CANCELED`다.
- 취소가 발생하면 고객 채팅방에 시스템 메시지가 저장된다.
- 프론트는 채팅방 메시지 스트림에서 취소 상태 변화를 그대로 표시한다.

## 화면 해석

- 취소 후 고객 채팅방에는 예약 취소 시스템 메시지가 하나 쌓인다.
- 메시지 문구와 사유 표시는 다음 이슈에서 확장한다.
