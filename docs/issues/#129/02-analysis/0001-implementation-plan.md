# `#129 예약 상세 응답 총액 추가` 구현 계획

작성일: `2026-06-18`  
기준 이슈: `#129`  
관련 브랜치: `feature/#129`

## 목적

예약 상세 바텀시트에서 메뉴별 가격과 함께 총액을 보여줄 수 있도록, 예약 상세 응답에 총액 필드를 추가한다.

이 이슈는 예약 상세 응답의 보강에만 집중한다. 예약 액션, 변경 이력, 고객 자동 메시지, 캘린더 추가 기능은 후속 이슈로 분리한다.

## 구현 원칙

- 기존 예약 상세 API 경로는 유지한다.
- 예약 상세 응답에 `menus[]`는 그대로 유지한다.
- 총액은 예약 시점 스냅샷 가격(`priceSnapshot`) 기준으로 계산한다.
- 가격이 없는 메뉴는 합산에서 제외한다.
- 프론트는 `menus[]`와 `totalPrice`를 함께 사용해 상세 바텀시트를 렌더링한다.

## 현재 문제

- 예약 상세 응답에는 메뉴별 `priceSnapshot`이 있지만 총액이 없다.
- 상세 바텀시트에서 총액을 계산하려면 프론트가 직접 합산해야 한다.
- 가격이 없는 메뉴가 섞였을 때 총액 표시 기준을 백엔드가 명시하지 않는다.

## 목표 범위

### 포함

- `ReservationDetailResponse`에 총액 필드 추가
- 예약 상세 조회에서 메뉴별 `priceSnapshot`을 합산해 총액 반환
- 가격이 없는 메뉴는 합산에서 제외
- 메뉴 목록이 비어 있으면 총액은 `null`

### 제외

- 예약 액션 API
- 예약 변경 이력 API
- 고객 자동 메시지
- 캘린더 예약 블록/일간 타임라인 변경
- 테스트 추가

## 최소 변경 단위

### 변경 단위 1

- 목표: 예약 상세 응답에 총액 필드를 추가한다.
- 분류: `Structural`
- 수정 대상:
  - `src/main/java/com/example/easybooking/reservation/dto/ReservationDetailResponse.java`
- 검증: 컴파일 시 응답 DTO가 새로운 필드를 포함한다.
- 완료 조건: 예약 상세 응답 타입이 총액 필드를 표현할 수 있다.

### 변경 단위 2

- 목표: 예약 상세 조회에서 총액을 계산해 내려준다.
- 분류: `Behavioral`
- 수정 대상:
  - `src/main/java/com/example/easybooking/reservation/service/ReservationService.java`
- 검증: 컴파일 및 수동 응답 확인
- 완료 조건: 메뉴별 가격 합산이 예약 상세 응답에 반영된다.

## 리스크와 대응

### 리스크 1. 일부 메뉴 가격이 null인 경우

대응: null 가격은 합산에서 제외하고, 총액이 전부 null이면 응답 총액도 null로 둔다.

### 리스크 2. 기존 클라이언트의 DTO 역직렬화

대응: 새 필드는 추가만 하므로 기존 필드 의미는 유지된다.

- [ ] 예약 상세 조회가 총액을 계산해 내려준다.
- [ ] 컴파일이 통과한다.
