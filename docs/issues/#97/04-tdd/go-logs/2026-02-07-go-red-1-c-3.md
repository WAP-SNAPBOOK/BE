## 1) 어떻게 변경할지 (설계/접근 방식)

### 핵심 아이디어

- `@DataJpaTest` 기반의 **JPA 매핑 테스트**를 하나 추가한다.
- 테스트가 **컴파일**되도록 `Reservation`에 `durationMinutes` 접근 API를 최소로 추가한다.
- 단, 이번 단계(RED)에서는 실제 DB 매핑이 아직 “없어야” 하므로 `durationMinutes`는 **`@Transient` 임시 필드**로 추가한다.
  - 그러면 저장/조회 후 `durationMinutes`가 DB로부터는 복원되지 않아, 기대값(60)과 실제(null)가 달라 **테스트가 실패(RED)** 한다.

### 추가/변경 대상

- 테스트 신규 추가
  - `src/test/java/com/example/easybooking/reservation/domain/ReservationJpaMappingTest.java`
- 임시(RED용) 최소 변경
  - `src/main/java/com/example/easybooking/reservation/domain/Reservation.java`
    - `durationMinutes` 필드 추가(임시: `@Transient`)
    - `durationMinutes` 값을 설정할 public 메서드 1개 추가

## 2) 변경 근거 (이유, 장단점)

### 왜 JPA 매핑 테스트인가

- `duration_minutes`는 “비즈니스 로직”이 아니라 **엔티티 ↔ DB 컬럼 매핑** 품질이 핵심이라, 가장 작은 단위로 검증하기 좋다.
- 서비스/컨트롤러까지 끌고 가지 않고도, `EntityManager`로 flush/clear 후 재조회하여 **“진짜 DB round-trip”** 을 확인할 수 있다.

### 왜 `@Transient` 임시 구현인가 (RED 단계 정책 준수)

- 현재 `Reservation`에 `durationMinutes`가 없어서 테스트가 컴파일조차 안 된다.
- RED 단계에서는 “최소 임시 구현(컴파일만)”이 허용되므로,
  - **컴파일을 위한 최소 API만 추가**하고
  - 실제 영속화는 되지 않게(`@Transient`)
  - 테스트가 의미 있게 실패하도록 만든다.

### 장단점

- 장점
  - 실패 원인이 명확(“DB에 저장되지 않음”)하고, GREEN 단계에서 `@Column(name="duration_minutes")`로 전환하면 자연스럽게 해결된다.
  - 스키마/마이그레이션 유무와 무관하게 RED를 만들 수 있어 안정적이다.
- 단점/주의
  - `@Transient`는 임시 상태이므로, GREEN 단계에서 반드시 제거/변경해야 한다.
  - 필드/메서드 이름(`durationMinutes`)은 이후 API 설계와 일관되게 유지해야 한다.

## 3) 코드 수정 예시 (diff 또는 예시 코드)

### (예시) `Reservation`에 임시 필드/메서드 추가 (RED용)

```diff
// Reservation.java
+ import jakarta.persistence.Transient;
 
 public class Reservation {
   // ...
+  @Transient
+  private Integer durationMinutes;
+
+  public void setDurationMinutes(Integer durationMinutes) {
+      this.durationMinutes = durationMinutes;
+  }
 }
```

### (예시) JPA 매핑 테스트 추가 (실패해야 정상: RED)

```java
@DataJpaTest
class ReservationJpaMappingTest {

    @Autowired EntityManager em;

    @Test
    void canPersistAndLoadDurationMinutes() {
        Reservation r = Reservation.createReservation(
                1L,
                1L,
                2L,
                LocalDate.of(2026, 2, 5),
                LocalTime.of(14, 0),
                "{}",
                List.of()
        );
        r.setDurationMinutes(60);

        em.persist(r);
        em.flush();
        em.clear();

        Reservation found = em.find(Reservation.class, r.getId());
        assertThat(found.getDurationMinutes()).isEqualTo(60); // RED: 실제는 null
    }
}
```
