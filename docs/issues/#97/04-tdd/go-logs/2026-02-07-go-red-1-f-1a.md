## go(RED) — #97 / 1-F-1a `durationMinutes` 30분 단위 검증

- 날짜: 2026-02-07
- 이슈: `#97`
- plan 항목: `docs/issues/#97/04-tdd/plan.md`의 **1-F-1a**
- 목표(RED): **테스트 추가 후 실패(RED) 확인**까지만 수행한다. (GREEN 구현은 다음 `go`)

---

## 1) 어떻게 변경할지 (설계/접근 방식)

- 검증 위치는 **`ReservationConfirmRequest`(DTO) + Bean Validation**으로 둔다.
  - `ReservationController.confirmReservation(...)`가 `@Valid`로 요청 바디를 검증하므로, DTO 레벨에서 제약을 추가하면 **요청 단계에서 즉시 400**으로 차단할 수 있다.
- 이번 항목(1-F-1a)은 “30분 단위만 허용”만 다룬다.
  - `null/0/음수` 정책은 `plan.md`에 적힌 대로 **후속 테스트에서 결정**해야 하므로, 이번에는 “값이 주어졌을 때 30의 배수인지”만 강제한다.
- 테스트는 MVC까지 가지 않고, **jakarta validation `Validator`로 DTO를 직접 검증**한다.
  - 입력: `message="ok"`, `durationMinutes=45`
  - 기대: constraint violation 1개 이상 발생

---

## 2) 변경 근거 (이유, 장단점)

- **이유**
  - 점유 블록(`ReservationTimeBlock`)이 30분 단위로 생성되므로, 확정 입력이 30분 단위를 벗어나면 도메인/DB 정책과 어긋난다.
  - 가장 빠른 피드백은 요청 DTO 검증이며, 서비스 로직까지 내려가기 전에 잘못된 입력을 차단할 수 있다.
- **장점**
  - 구현 영향이 작고(DTO 제약 + 단위 테스트), 실패 지점이 명확하다.
  - `null` 정책을 아직 결정하지 않았더라도(후속 항목), **`null`은 검증 통과로 두고** 이번 항목의 범위를 유지할 수 있다.
- **단점/주의**
  - `@AssertTrue` 기반 검증(메서드 레벨)을 쓰면, violation 경로가 필드가 아니라 메서드명으로 잡힐 수 있다.
  - 현재 `GlobalExceptionHandler`는 validation 예외를 커스텀 포맷(`ErrorResponse`)으로 변환하지 않으므로, API 레벨에서 “에러 바디 포맷”까지 고정하려면 추가 작업이 필요할 수 있다(이번 항목에서는 상태 코드/violation 여부만 우선 고정).

## 3) 코드 수정 예시 (diff 또는 예시 코드)

### (A) RED: 먼저 실패 테스트 추가

```java
class ReservationConfirmRequestValidationTest {
  private final Validator validator = Validation.buildDefaultValidatorFactory().getValidator();

  @Test
  void validate_fails_whenDurationMinutesIsNotMultipleOf30() {
    ReservationConfirmRequest req = new ReservationConfirmRequest();
    req.setMessage("ok");
    req.setDurationMinutes(45);

    Set<ConstraintViolation<ReservationConfirmRequest>> violations = validator.validate(req);

    assertThat(violations).isNotEmpty(); // RED(현재): 비어있어서 테스트가 실패할 것
  }
}
```

### (B) GREEN(다음 go에서): DTO에 “30분 단위” 제약 추가(최소)

```java
@AssertTrue(message = "예약 기간은 30분 단위(30, 60, 90, ...)만 허용됩니다.")
public boolean isDurationMinutesOn30MinuteBoundary() {
  if (durationMinutes == null) return true; // null 정책은 후속 항목에서 결정
  return durationMinutes % 30 == 0;
}
```
