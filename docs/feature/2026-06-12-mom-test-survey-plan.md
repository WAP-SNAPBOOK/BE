## 핵심 원칙

`The Mom Test`에서 확인한 방향은 다음과 같다.

- `SnapBook이 좋을 것 같나요?`처럼 아이디어 평가를 묻지 않는다.
- 미래 의향보다 최근 실제 행동을 묻는다.
- 칭찬, 예의상 긍정, 막연한 의견은 검증 근거로 쓰지 않는다.
- 문제의 빈도, 최근 사례, 현재 대안, 시간/돈 손실을 확인한다.
- 마지막에는 다음 행동 약속을 확인한다. 예: 파일럿 참여, 실제 예약 링크 테스트, 기존 예약 관리 화면 공유.

## 조사 목표

SnapBook의 핵심 가설을 다음 4개로 나눠 검증한다.

1. 사장님은 예약, 상담, 사진 요청이 여러 채널에 흩어져 실제 운영 비용을 겪고 있다.
2. 현재 도구만으로는 예약 확정/거절, 문의 답변, 사진 확인 흐름이 자연스럽게 이어지지 않는다.
3. 고객도 예약 전후 상담과 사진 전달 과정에서 불편을 겪는다.
4. 사장님은 문제 해결을 위해 시간, 돈, 운영 방식 변경 중 하나 이상을 실제로 감수할 수 있다.

## 조사 대상

### 1차 대상

- 인스타그램, 카카오톡, 네이버 예약, 전화 중 2개 이상 채널로 예약/문의를 받는 소규모 매장 사장님
- 네일, 속눈썹, 미용, 사진관, 공방, 1인 예약제 서비스처럼 상담과 사진 참고가 예약에 영향을 주는 업종

### 2차 대상

- 위 업종에서 최근 1개월 내 예약하거나 문의한 고객

## 사장님 대상 설문 질문

설문은 5분 안에 끝나게 만들고, 응답이 유의미한 사람만 후속 인터뷰로 연결한다.

### 기본 분류

1. 운영 업종은 무엇인가요?
2. 하루 평균 예약/문의는 몇 건 정도인가요?
3. 현재 예약/문의가 들어오는 채널을 모두 골라주세요.
4. 예약 확정, 변경, 취소를 기록하는 주 도구는 무엇인가요?

### 최근 행동 확인

5. 가장 최근 예약 3건은 각각 어떤 채널로 들어왔나요?
6. 최근 1주일 동안 예약 정보가 누락되거나 헷갈린 적이 있었나요? 있었다면 어떤 상황이었나요?
7. 고객이 참고 사진이나 요청사항을 보낸 경우, 지금은 어디에 저장하거나 다시 확인하나요?
8. 예약 확정/거절/변경 내용을 고객에게 다시 안내할 때 보통 어떤 순서로 처리하나요?

### 비용과 불편 확인

9. 예약/문의 정리에 하루 평균 몇 분 정도 쓰나요?
10. 가장 번거로운 작업은 무엇인가요?
11. 예약 실수나 답변 지연 때문에 실제 손해가 난 적이 있나요? 있다면 최근 사례를 적어주세요.
12. 현재 예약/상담 관리를 위해 유료 도구나 광고, 외주, 추가 인력을 쓰고 있나요?

### 현재 대안 확인

13. 지금 쓰는 방식에서 계속 유지하고 싶은 점은 무엇인가요?
14. 지금 쓰는 방식에서 반드시 바꾸고 싶은 점은 무엇인가요?
15. 비슷한 문제를 해결하려고 다른 앱이나 서비스를 써본 적이 있나요? 왜 계속 쓰거나 중단했나요?

### 다음 행동 확인

16. 1주일 동안 실제 고객 예약 링크로 테스트해볼 수 있나요?
17. 가능하다면 현재 예약/문의 처리 흐름을 15분 정도 화면 공유로 보여줄 수 있나요?
18. 유료라면 어떤 조건일 때 월 비용을 낼 수 있나요?

## 고객 대상 설문 질문

고객 설문은 사장님 문제를 보조 검증하는 용도로 사용한다.

1. 최근 1개월 내 예약한 업종은 무엇인가요?
2. 예약 전 문의는 어떤 채널로 했나요?
3. 예약 전 참고 사진이나 요청사항을 보낸 적이 있나요?
4. 예약 확정 여부를 어디에서 확인했나요?
5. 답변 대기, 사진 재전송, 예약 시간 착오, 요청사항 누락 중 겪어본 문제가 있나요?
6. 예약 과정에서 가장 불편했던 최근 사례를 적어주세요.
7. 다음 예약 때 한 화면에서 문의, 사진 전달, 예약 확인이 같이 된다면 어떤 상황에서 유용할 것 같나요?

## 피해야 할 질문

아래 질문은 호감도만 만들 가능성이 높아 설문 본문에서는 제외한다.

- `SnapBook을 쓰고 싶나요?`
- `이런 서비스가 있으면 좋을 것 같나요?`
- `월 1만 원이면 결제하시겠어요?`
- `예약 관리가 불편하시죠?`
- `저희 아이디어에 대해 어떻게 생각하세요?`

대신 이렇게 바꾼다.

- `가장 최근 예약 변경은 어떤 채널에서 들어왔고, 어디에 기록했나요?`
- `최근 예약 실수나 누락이 있었던 마지막 상황을 설명해주세요.`
- `지금 이 문제를 해결하려고 돈이나 시간을 쓰고 있는 것이 있나요?`
- `현재 방식에서 다른 서비스로 바꾸지 못하는 이유는 무엇인가요?`

## 응답 해석 기준

우선순위가 높은 응답자는 다음 조건을 많이 만족하는 사람이다.

- 예약/문의 채널이 2개 이상이다.
- 사진, 요청사항, 상담 내용이 예약 결정에 영향을 준다.
- 최근 1개월 내 예약 누락, 답변 지연, 정보 재확인 문제가 있었다.
- 현재 관리 방식에 시간 또는 비용을 이미 쓰고 있다.
- 파일럿 테스트, 화면 공유, 기존 데이터 공유 중 하나에 동의한다.

반대로 `좋을 것 같다`, `나중에 써보겠다`, `있으면 편하겠다`만 있는 응답은 검증 근거로 약하게 본다.

## 권장 진행 방식

1. 온라인 설문으로 사장님 30명, 고객 30명을 먼저 모은다.
2. 사장님 응답 중 우선순위 조건을 만족하는 5명만 20분 인터뷰한다.
3. 인터뷰에서는 실제 최근 예약 1건의 흐름을 처음부터 끝까지 재구성한다.
4. 파일럿 동의자에게만 SnapBook 예약 링크를 제공하고 1주일 동안 실제 사용을 관찰한다.
5. 판단 지표는 `파일럿 전환 수`, `실제 예약 링크 사용 수`, `반복 사용 의향`, `유료 조건`으로 본다.
