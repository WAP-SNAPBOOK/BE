# Specification Template

최종 산출물은 아래 4개 파일로 분리한다.

- `prd.md`
- `feature-spec.md`
- `tech-api-spec.md`
- `acceptance-criteria.md`

문서 메타데이터와 변경 이력은 기본 포함하지 않는다.
각 문서는 `확정된 정보`, `열린 질문`, `가정`을 기본 구조로 가진다.
