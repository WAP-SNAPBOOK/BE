# DocOps 결정 기록: 브랜치가 아닌 “이슈 번호” 단일 루트

- 작성일(런타임): 2026-01-26
- 결정 요약: 문서 산출물 루트는 **브랜치명 없이**, 이슈 번호만으로 결정한다.

## 1) 결정(Decision)
- 작업 시작 시 **이슈 번호는 필수**다.
- 이슈 번호가 없으면 AI는 **반드시 이슈 번호를 요구하고 중단**한다.
- 모든 문서/스킬 산출물 저장 루트는 아래로 통일한다.
  - `docs/issues/#<issue-number>/...`

## 2) 배경(Context)
- 브랜치 기반 경로는 worktree/브랜치 운영 방식에 따라 경로가 흔들리고,
  실제 작업 단위(이슈)를 찾는 데에는 이슈 기반 정렬이 더 유리하다.

## 3) 대안(Options)
- A) `docs/<type>/<owner>/<branch-name>/issues/#<issue-number>/...`
  - 장점: 브랜치/오너 분리로 충돌 가능성 낮음
  - 단점: 브랜치에 종속(요구사항과 불일치)
- B) `docs/issues/#<issue-number>/...`  ✅ 채택
  - 장점: 작업 단위가 가장 선명(이슈 번호만 알면 탐색 가능)
  - 단점: 여러 작업자가 동시에 같은 이슈 번호로 작업하면 충돌 가능(운영으로 방지)

## 4) 결과/영향(Consequences)
- Cursor rules/skills는 앞으로 “이슈 번호 입력”을 게이트로 삼는다.
- `plan.md`(SSOT) 기본 위치도 이슈 루트 아래로 고정된다.
